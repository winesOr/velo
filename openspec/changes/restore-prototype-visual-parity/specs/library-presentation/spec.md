# Spec Delta

## Purpose

通过紧凑的搜索、类型与筛选工具行组织真实媒体库，同时保留各媒体服务器不同的查询能力、来源身份与分页语义，让手机海报墙与电视筛选布局都容易理解。

## ADDED Requirements

### Requirement: 浏览工具行

系统 SHALL 在手机呈现搜索、媒体类型Tab和筛选排序入口，将详细条件收进悬浮弹窗；TV 保留侧栏筛选和右侧海报墙。

#### Scenario: 组合筛选
- **WHEN** 用户输入关键词并选择年份和观看状态
- **THEN** 保留条件并刷新对应查询，工具行显示当前条件摘要

### Requirement: 真实海报与来源

系统 SHALL 参考三列手机及自适应TV海报墙展示真实评分和来源Logo；跨服务器分组、分页和不支持条件的提示不得伪装为全库合并结果。

#### Scenario: 来源能力不同
- **WHEN** 用户选择全部来源并开启某来源不支持的条件
- **THEN** 显示能力限制，分组结果仍对应正确服务器
