# Spec Delta

## Purpose

把真实设置能力组织为易扫描的分类首页与电视双栏详情，提供服务器身份摘要、播放字幕弹幕和外观入口，并在调整外观时保持已有持久配置与跨入口一致性。

## ADDED Requirements

### Requirement: 分组和入口

系统 SHALL 在手机设置首页提供身份摘要、观看体验、个性化及资源服务分组，包含播放、字幕、弹幕、一起看、外观及连接下载入口；TV 保留左分类右详情。

#### Scenario: 进入设置
- **WHEN** 已连接服务器的用户打开手机或TV设置
- **THEN** 显示真实协议Logo与账户摘要，各入口仍进入已有参数和管理功能

### Requirement: 外观和持久化

系统 SHALL 复用现有持久设置，显示浅色深色跟随系统选择及当前值；未实现的内核或模拟网络测试不得显示成功。

#### Scenario: 重启恢复
- **WHEN** 手动选择浅色后重启应用
- **THEN** 设置与浏览页恢复浅色，多入口参数保持一致
