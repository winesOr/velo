# Spec Delta

## Purpose

提供以真实媒体与服务器版本为依据的电影和剧集详情，统一主视觉、播放操作、来源和内容信息，使用户在选择剧集或版本后能理解将播放的内容与技术属性。

## ADDED Requirements

### Requirement: 详情层级

系统 SHALL 展示清晰海报、整页媒体色、Logo或26号文字回退、紧凑元信息、独立主播放及收藏已看操作；影片无选集，剧集保留季与选集。

#### Scenario: 查看电影剧集
- **WHEN** 用户分别打开电影和多季剧集
- **THEN** 两类内容均有完整详情，电影不显示无效季控件；长标题可读

### Requirement: 来源和技术信息

系统 SHALL 展示真实来源Logo及可用版本，在底部展示实际视频音频字幕与文件信息；信息 SHALL 对应当前播放目标，缺失时明确空态且不使用示例值。

#### Scenario: 切换版本或集
- **WHEN** 用户选择其他版本或当前剧集
- **THEN** 后续播放及技术信息对应选择，旧异步结果不覆盖新目标

### Requirement: 内容区

系统 SHALL 保留简介、演员、类型、相关推荐及全部选集入口；长剧可按组定位，TV 所有新增操作均可遥控到达。

#### Scenario: 长剧定位
- **WHEN** 用户在多季长剧中选择后续分组并返回
- **THEN** 跳转到正确集组，既有分页及焦点记忆继续有效
