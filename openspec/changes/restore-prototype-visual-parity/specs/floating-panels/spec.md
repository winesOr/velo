# Spec Delta

## Purpose

为浏览菜单、普通选择和播放器参数提供一致的悬浮呈现，让手机与电视操作不再依赖贴底面板，并在嵌套操作、输入键盘和返回过程中保持焦点与业务状态。

## ADDED Requirements

### Requirement: 浮层位置

系统 SHALL 将按钮菜单呈现为锚点菜单、普通选择呈现为居中四角圆润弹窗、播放器参数呈现为侧面悬浮面板；均不得从屏幕底部贴边滑入或显示拖动把手。

#### Scenario: 打开参数
- **WHEN** 用户打开服务器菜单、筛选或播放参数
- **THEN** 分别在按钮附近、页面中心或播放右侧呈现，长内容可滚动

### Requirement: 返回与焦点

系统 SHALL 保留浮层内焦点约束、嵌套返回、遮罩关闭与触发点焦点恢复；输入键盘不得遮挡确认操作。

#### Scenario: 遥控嵌套返回
- **WHEN** TV 用户进入参数子页后连续按返回
- **THEN** 先回上级再关浮层，焦点回到有效触发控件
