# Spec Delta

## Purpose

将首页正在显示的实际图片与媒体身份作为主题依据，统一海报交叉过渡、页面背景和导航的时间进度，使快切、加载失败和系统外观变化都保持视觉连续与可操作性。

## ADDED Requirements

### Requirement: 连续图片主题

系统 SHALL 从当前实际显示图片采样，并连续更新背景、渐变与导航；采样等待期间保留当前显示色，旧结果不得覆盖新图。

#### Scenario: 连续快切
- **WHEN** 快速切换三张海报或同片背景自动换图
- **THEN** 最终图片、内容和色彩一致，过程不插入默认色

### Requirement: 首页交互

系统 SHALL 在手机显示通栏清晰海报、居中片名、分页点及横向继续观看；推荐点击进入详情，滑动或分页点换片，不显示左右箭头。

#### Scenario: 推荐与续播
- **WHEN** 用户点击推荐主视觉后返回并选择继续观看
- **THEN** 推荐打开对应详情，继续观看沿用真实续播策略

### Requirement: 失败与减少动态

系统 SHALL 在图片失败时保留标题和入口，并在减少动态效果时停止自动换片与颜色补间。

#### Scenario: 图片失败
- **WHEN** 当前图片请求失败或用户开启减少动态效果
- **THEN** 显示稳定兜底且页面可用，无自动持续动画
