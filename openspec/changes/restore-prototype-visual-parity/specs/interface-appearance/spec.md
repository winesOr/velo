# Spec Delta

## Purpose

统一各页面的明暗外观、字号与图标语言，使用户在服务器浏览、设置及导航之间切换时获得连续清晰的视觉层级，并保留系统字号和已有外观偏好。

## ADDED Requirements

### Requirement: 外观一致性

系统 SHALL 支持浅色、深色、跟随系统并恢复已保存选择；首页、导航和浮层 SHALL 响应同一外观，播放器维持中性暗色。

#### Scenario: 系统切换
- **WHEN** 选择跟随系统并改变系统外观
- **THEN** 首页和普通页面同时切换；手动选择不被系统覆盖

### Requirement: 紧凑导航与身份

系统 SHALL 使用线性操作图标、真实 Emby/Jellyfin/Plex 标识及无投影导航。普通字号手机页面标题为 22、TV 为 24，导航标签为 10；大字体不得裁切操作。

#### Scenario: 切换来源
- **WHEN** 用户选择不同协议服务器
- **THEN** Logo 随服务器变化；底栏与选中项均无投影且两种外观下可辨认
