# Spec Delta

## Purpose

在视频画面之上提供中性清晰的控制层、轨道摘要与悬浮参数，使用户直接了解当前音轨字幕和播放设置，同时完整保留现有时间轴、弹幕热力及跳过撤销的交互。

## ADDED Requirements

### Requirement: HUD和参数

系统 SHALL 保留返回侧Logo、播放控制及时间轴，显示可用轨道与倍速摘要，并通过右侧浮层调整参数；控件隐藏后不残留独立Logo。

#### Scenario: 选择轨道
- **WHEN** 用户切换音轨或字幕并关闭参数面板
- **THEN** 摘要反映播放器真实选择，恢复控制层自动隐藏与触发焦点

### Requirement: 既有播放能力

系统 SHALL 保持热力、缓冲、章节、缩略图、拖动取消与跳过撤销行为；无真实支持时不展示可操作投屏或VLC。

#### Scenario: 播放回归
- **WHEN** 拖动时间轴后取消或执行跳过撤销
- **THEN** 取消不提交seek，撤销回到当前片的跳前位置，热力绘制不破坏章节
