# 融合媒体库与设置实现说明

对应 OpenSpec 变更 `plan-plezy-fusion-redesign` 的 6.1–6.5。这里描述真实 Flutter 页面、既有客户端与设置存储，不把 HTML 原型里的示例内容、地址和播放核心视为已实现能力。

## 媒体库入口与查询范围

- 没有保存过页签的媒体库默认进入海报墙；已有推荐、浏览、合集、播放列表偏好仍按名称恢复。
- 来源选择器新增“全部来源”；桌面与 TV 的工具栏另有叠层图标入口。单库页的已有筛选、排序和保存偏好不被聚合页覆盖。
- “全部来源”按来源与媒体库分组，每组标题标明库名、服务器名和后端。组的顺序沿用媒体库顺序，不把部分加载的数据伪装成跨服务器全局排名。
- 聚合页的公共搜索、种类、精确年份、已看／未看和排序分别发送到每个适用媒体库的服务端。排序只在组内生效；电影条件不会把剧集库的根目录当作电影结果查询。
- 聚合页不提供类型／地区的跨服统一 facet 值：Plex 的值可能是来源内部 ID，不能直接当成另一个服务器的名称。页面明确解释此限制，并要求进入单库使用后端支持的完整筛选。没有下载部分页面后本地过滤、却宣称筛选覆盖全库的行为。
- 聚合页不显示可疑的精确总数。现有客户端在后端不返回精确总数时用多一条的哨兵维持分页，不能把该值展示成真实总量。

## 单库能力矩阵

| 条件 | Plex | Jellyfin | Emby |
| --- | --- | --- | --- |
| 库内搜索 | `title` | `SearchTerm` | `SearchTerm` |
| 内容种类 | 已发布的分组／元数据类型 | `IncludeItemTypes` | `IncludeItemTypes` |
| 类型 | 库声明的 schema 与操作符 | `Genres`，等值 | 同左 |
| 年份 | 库声明的操作符；允许范围时提供范围 | `Years`，精确年份 | 同左 |
| 地区 | 仅库声明 `country` 时 | 不支持 | 不支持 |
| 已看／未看 | 库声明的布尔条件 | `Filters=IsPlayed/IsUnplayed` | 同左 |
| 仅观看中 | 不凭空增加条件 | 不支持 | 不支持 |
| 标题／评分／日期排序 | 服务端公布的排序项 | 既有 translator 的支持列表 | 同左 |

`LibraryBrowseCapabilities` 在请求前检查恢复的筛选。MediaBrowser 不支持的任意排除、年份范围或同一字段的多个 AND 条件不会假装已应用，页面会提示移除不支持的旧条件。类型值发现失败也有明确反馈，不因此清空已经有效的浏览结果和可支持的筛选。

库内搜索使用 `LibraryQuery.search`，编辑时立即废弃旧请求和分页，再等待 350 ms 防抖请求。切换单库清空临时搜索与定时器。筛选之间为 AND，同一筛选的多个值为 OR；重置清除搜索、筛选、字母前缀、自定义排序和分组，并从 offset 0 重新请求。

## 独立分页与异步隔离

单库仍由 `PaginatedItemLoader` 和 `BaseLibraryTabState` 管理取消与请求代次。筛选／排序编辑器记录打开时的媒体库归属，异步返回不能把旧来源的草稿保存到新来源。

聚合页新增 `GroupedLibraryController`：

- 每个 `library.globalKey` 对应独立 items、offset、total、loading、error 和取消控制器；同名库、同 ID 媒体不混用来源。
- 每组有自己的“加载更多”或“重试”。某组下一页失败保留该组已加载内容，其他组不被清空或阻塞；重试继续原 offset。
- 搜索、筛选、来源列表或手动刷新改变时，立即取消旧代次；即使后端没有真正停止旧响应，也不会把迟到结果写回新查询。
- 聚合结果使用单独的 `all_sources_grouped_results` 滚动存储键，不复用单库位置。刷新重置聚合查询游标；返回媒体库时检查来源内容 epoch，处理离开期间的服务端更新。
- 卡片 key 同时包含媒体库和带服务器身份的媒体 ID。卡片详情／播放继续使用原始响应的服务器身份，不靠媒体 ID 猜测客户端。

## 手机、TV 与设置

手机在 390 px、默认字号下显示三列竖海报；窄屏和大字按可读最小宽度降低列数。共享网格新参数默认关闭，其他页面不改变既有布局。已有图片回退、年份／评分、已看／进度标记，以及音乐方形／圆形布局继续复用。

TV 使用 220 px 条件侧栏和右侧海报墙。单库沿用既有稀疏加载与焦点策略；聚合组采用独立加载更多按钮，卡片左右键能回到条件区，右键进入真实卡片或可操作状态。网格方向键使用实际布局列数，不按固定截图猜测列数。

手机设置首页按连接、弹幕、通用／播放／外观、一起看、下载、控制和高级功能组织。原有账户、服务、备份、更新、日志和关于仍可访问。TV 使用分类栏与详情栏，左右键交接焦点并保留选中分类，详情复用既有设置控件与存储。

`DanmakuSettingsEntry` 初始化并监听播放使用的同一 `DanmakuSession`，手机打开同一 `DanmakuSettingsSheet`，TV 内嵌同一面板，没有第二套会覆盖播放端新值的快照。初始化失败可重试。样式、密度、过滤、热力图、来源管理、本地导入与持久化仍由共享弹幕模块负责。

一起看中继设置移动到对应分组，保留既有 HTTP(S) 校验。启动目的地包含原有选项及一起看、设置、下载、发现，与导航稳定 ID 对应。没有添加不可用的 VLC 开关、云盘连接、二维码配置或手机同步承诺；mpv／ExoPlayer 的平台能力不变。

## 回退

回退页面、能力校验、聚合 controller 和可选网格参数不会删除已有服务器连接或单库偏好；聚合选择使用专用存储哨兵，不伪装成库 ID。弹幕偏好继续归共享仓库所有，本范围没有新增通用设置键或手工修改生成领域模型。
