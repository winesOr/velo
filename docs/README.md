# Development Notes

This directory contains historical implementation and design notes from local development. They are context, not
a current feature matrix, release announcement, or proof that a platform has passed acceptance testing.

The initial public Velo repository is a fresh source snapshot derived from Plezy, not a publication of the original
local Git history. Existing code and license notices are retained; see the project README for upstream attribution.

The following local-only material is deliberately excluded:

- Third-party APKs, reverse-engineering exports and the `reference/` evidence directory.
- Build output, signing files, local server data, editor configuration and native-library archives.
- Private QA screenshots and prototype artwork, including crops of third-party application screenshots.
- The upstream Plezy marketing website and package-manager distribution files.

Some historical links point to these omitted artifacts. Local paths in notes are represented as `<repo>`,
`<flutter-sdk>` or `<jdk-home>`. Use source, tests and fresh device observations to verify current behavior.
