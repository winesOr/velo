# P9-1 弹层与可达性审计

本次核对了以下 15 个实际入口的源码、已运行的相关测试证据及关闭层级。没有新增审计测试、TV 自动化或 golden。没有连接实体设备，表中的结果不代表读屏、遥控器或实际视距验收。

| 入口 | 核对结果 |
| --- | --- |
| 首页/详情评分来源 | 复用来源 dialog，范围和尺度真实，关闭回焦，不替换个人评分编辑 |
| TV 完整媒体说明 | 独立可滚动 dialog，返回键先关闭本层 |
| 收藏加载提示 | 目标身份与防重入守卫，失败清理加载状态，迟到结果不写入其他条目 |
| 已看加载提示 | 保留在线/离线路径、权限和失败语义 |
| 媒体库筛选/字段子页 | 按媒体库提交，返回先退出字段子页 |
| 媒体库排序 | 修复延迟初始聚焦：用户键盘/指针操作后取消，校验当前焦点、路由和页面 TickerMode，销毁时移除监听与计时器 |
| 创建房间 | 仅房主默认，名称可选，提交防重，目标作用域守卫 |
| 加入房间 | 校验真实邀请码合同，错误就地显示，保留输入并支持重试 |
| 邀请码复制 | 完整邀请码语义、独立复制入口和统一通知 |
| 音轨与主/次字幕 | 共用事务锁，等待完成，失败回滚，保留 Off 与互斥规则 |
| 在线字幕搜索/语言子页 | 父抽屉内分层返回，失败保留状态 |
| 版本/质量、缩放、睡眠子页 | P7-2 已修复 embedded 返回键：先回父设置，再关闭抽屉 |
| 弹幕源删除 | 抽屉内独立确认，取消保留，确认后校验来源身份与忙态 |
| 图片缓存清理 | 确认/取消、防重复提交、失败反馈与 mounted 守卫 |
| 字幕语言账户偏好 | 导航前后使用当前账户列表，保留空态、加载、错误及服务器能力限制 |

审计发现的两个源码问题分别已在 P7-2（嵌入式子页返回）和本包（排序延迟抢焦点）修复。排序修复只修改 `lib/screens/libraries/sort_bottom_sheet.dart`，保留排序、方向、清除和菜单接口；现有排序测试 2 个通过，改动文件分析无错误或警告，仅 SDK 的 material 导入弃用提示。

共享来源 dialog、OverlaySheet、设置抽屉、通知 helper 和账户偏好控制器均复用前序实现。本包未新增协议、默认值、服务或待定业务数值。TV 播放器方向路径已经源码人工走查；手机、平板、实体 TV 与读屏仍需设备验收。全量回归由 P9-2 执行。
