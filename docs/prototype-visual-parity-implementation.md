# 原型视觉还原实施记录

对应 `openspec/changes/restore-prototype-visual-parity/`，以 2026-10-23 最新 HTML 与 appearance.css 为视觉基线。此文记录本次应用代码增量；既有弹幕、播放、查询、房间及账户数据继续复用。

## 公共标准

- 普通暗色页面黑底、浅色 #f2f2f7；正文与导航前景分别配置。已有浅色/深色/跟随系统以及 OLED 持久偏好继续兼容。
- 页面标题手机22、TV24，二级20；详情文字回退26、内容区标题18。导航图标22、文字10，线性默认 fill0/weight400；实心语义状态可显式覆盖。
- 手机浮动导航普通字号高56、最大宽360，四入口保留，无外层或选中阴影；大字体允许增长高度而不裁切。
- `MonoPresentation` 保存布局和明暗海报映射。`HomeThemeScope` 是颜色插值的唯一时钟，导航不再开启第二条颜色动画；离开首页后导航回中性表面。

## 首页色彩与交互

`prepare(mediaKey)` 立即废弃旧媒体的待返回取色，保留当前颜色；`CyclingMediaBackdrop.onImageReady` 只报告实际解码图，包含同片换背景及图片失败回退。回调将同源图片限制为32×32采样，再按当前外观映射，过渡时长560ms，减少动态效果立即更新。采样和映射均为本项目设计，不宣称取得 VidHub 受保护方法体。

来源胶囊显示真实协议Logo和服务器名称；全部来源时按当前图显示协议标识并明确标为全部来源。菜单同时保留用户身份、刷新、遥控和退出。选择来源只过滤首页已加载推荐与继续观看，不改变账户可见服务器列表或其他页面的查询；来源结果不被声明为完整全库目录。主视觉打开详情，继续观看保留原策略，滑动和分页点可换片，没有左右箭头。

## 并行集成与验证

文件所有权见 change/design.md。共享翻译源和生成物由主代理集中生成；Flutter测试按模块排队，防止共享SDK及原生资源构建冲突。

基础回归覆盖：待取色期间不回默认色、代次隔离、中途反向补间、明暗映射与减少动态、实际换图回调，以及导航触控和TV键盘。

## 页面收口规则

- 详情使用连续海报底色，手机以独立播放键、收藏/已看及来源版本组织操作。选集保持最新 HTML 的横向卡片轨，分组只覆盖已经加载的数据，后续页保留加载入口；TV 沿用季分页、焦点记忆与方向键轨道。季详情的播放与技术信息共用当前选择的集。技术组件按目标、来源版本和代次隔离请求，缺数据或离线均不展示旧文件。
- 媒体库手机显示搜索、类型 Tab、筛选与排序；条件仍进入真实服务器查询。类型文字继承主题字体；聚合来源保留能力限制和分组分页。普通字号三列，大字体按现有密度策略降低列数。
- 设置按观看体验、个性化和资源服务分组，身份摘要来自实际账户/服务器，字幕入口复用现有页面。TV 保留分类与右侧参数，参数继续持久化。
- 一起看降低卡片高光，真实邀请码可复制且保留完整文本，窄屏允许换行；匹配、重连和准备状态继续来自协议。播放器轨道摘要读取实际轨道与倍速，侧浮层保留嵌套返回、键盘避让和焦点恢复。
