## 第一批 A：P1 常亮失败恢复（历史实施规格）

**目标**：常亮平台调用偶发失败后能够恢复；暂停、结束、最后 owner 退出仍能释放；播放器替换不会被旧页面释放。

**代码依据**：`lib/screens/video_player/wakelock_controller.dart` 已有 owner 集合、串行队列、期望/实际状态。当前 enable 失败会取消刷新，且未成功就不启动周期，因此缺少自动恢复。`video_player/parts/playback_services.dart` 在 completed=false 时重开完成锁存，但不补申请常亮；mpv EOF 又不一定产生 playing=false。

**实施**：

1. 将失败重试与成功周期重申分开，默认退避 1s / 2s / 5s，成功后每 5s 重申；配置可注入，日志按原因抑制重复。
2. 最新 desired 状态始终优先；最后 owner 关闭取消待重试；慢平台调用不堆积任务；失败不产生未处理异步异常。
3. 完成后回拖重播，在当前播放器仍有效、允许播放且已离开结束区域时恢复常亮；保留 automotive、TV 后台、屏幕交接等已有限制。

**非目标**：本批不在两个原生核心另行直接写 `FLAG_KEEP_SCREEN_ON`。多个独立持有者会与 Dart owner 竞争释放。ExoPlayer 将 isPlaying=false 映射为 pause 的缓冲语义涉及进度、媒体控制等，必须先形成状态契约再改。

**验收**：首次失败后成功；第 N 次周期失败后成功；持续失败有界退避；关闭取消；多 owner 交接；慢调用不堆积；排队回调不能在退出后重新获取；EOF 后回拖恢复，结束区域/暂停不误获取。真机另测连续播放至少 30 分钟、缓冲、暂停/结束/退出后正常熄屏。

## 第一批 B：P2 播放器选择器与局部 P8（历史实施规格）

**目标**：音频、主字幕和副字幕可清楚区分同语言轨道，长标题可读，触摸、键盘和 TV 都能完成选择与返回。

**实施**：

2. 接入播放器轨道抽屉；保留 source stream ID 与 mpv track ID 的区分、异步切换独占、外挂字幕、关闭字幕、主副字幕互斥和字幕搜索。
3. 短固定分段保留；剩余标签单行省略；源轨回调和选择成功后原有关闭行为不变。
4. 仅为新选择器加入局部按压/展开/焦点/禁用反馈。可新增 `press_feedback.dart` 与 `interaction_tokens.dart`，不得改变布局尺寸；滚动或取消手势即清除按压。

**接口交接**：B 在接入前确定新增组件的构造签名，并写入完成报告；C 不依赖或编辑该组件。本批 B 复用现有 audioLabel、subtitlesLabel、drawerSecondarySubtitle、common.off 等文案，确需新 key 由 C 串行追加。

**非目标**：本批不修改详情页预选，不批量迁移海报、导航、评分动画，不修改播放器选轨协议。

**验收**：60 字符以上标题、同语言三轨、无副标题、无轨/单轨/禁用/忙碌、当前项被删除后的回退、切换失败恢复、主副互斥与 off、外挂/source sidecar；菜单不越安全区，所有项可滚动到达；TV 打开聚焦当前项、选择只执行一次、返回恢复焦点；320/360px、200% 字号、RTL 不溢出；滚动不误触；减弱动画无缩放；按下/抬起/取消/禁用动画测试。按压包装不能再加第二个业务 onTap。

**验收**：0/1/2/5 输入来源、重复/未知/无效数字、缺失图标、320/360px 与 200% 字号、长标题、亮暗/OLED；窄布局换行/两列而非缩小文字；无分无空行；列表单分到详情补全无明显跳动且不混合剧集/剧评分；卡片开关、来源优先级与有效 userRating 个人优先生效；继续观看无角标；无额外网络请求；读屏包括来源和单位；TV 个人评分入口可达/可返回，无编辑能力时不产生假操作。

## P2 详情页预选：实施规格与验收

依赖 B/C 完成且共享详情页空闲。复用 `VideoPlayerScreen` 已有 preferredAudioTrack、preferredSubtitleTrack、selectedMediaIndex、selectedMediaSourceId 和版本偏好；先确认整个传递链再接三个选择器。手机三行、桌面/TV 三列，窄布局自动堆叠。

验收：版本切换后轨道重算；预选准确传到播放；不同后端 ID 不串用；离线下载版本可识别；无版本/无字幕/自动选择回退稳定；不新增第二套偏好。涉及公共播放接口时先提交契约报告再变更。

## P4 冷启动：实施规格与验收

**目标**：慢或离线服务器不阻塞已经可用的首页内容。**非目标**：不通过取消鉴权、混用用户缓存或吞掉错误“提速”。

先记录“进程启动→首个内容可见”与各阶段耗时；独立初始化按依赖并行；任一服务器可用或达到配置预算就展示首页；缓存先显再刷新、hubs 按服务器增量、下载元数据延后。建议等待默认 2s，作为可调配置而非承诺。

验收：改前/后各五次冷启动中位数；一台离线不拖住其他数据；全部离线有缓存/错误态与重试；切用户/注销不串缓存；刷新平滑；重连与取消无悬挂任务。未测基线前不宣称百分比收益。

## P5 运行性能：实施规格与验收

**目标**：减少下载事件风暴、无关重建与过重浮层效果。**非目标**：不盲目修改已有“并发更差”注释约束的 Jellyfin 详情路径。

下载进度按 key 节流，默认建议 300ms（可配置），状态改变立即通知且最后值必达；缓存视图、按条目 Selector；减少宽范围 provider watch；避免 build 创建 Future。Plex 详情先显已有内容再并行补充，必须用实测证明收益；模糊统一接入性能降级。

验收：事件风暴的通知计数与重建计数；完成/失败/删除即时；末值不丢；切页/销毁清理订阅；优化前后同设备帧时间与内存对比；降级后文本/焦点可见。具体性能预算在基线测量后写入任务卡。

## P6 显示与错误态：实施规格与验收

**目标**：优先修已复现的直播失败转圈/空白，再处理局部溢出、翻译和样式遗漏。**非目标**：不按旧文档重复全量弹窗迁移或顺便重构其他模块。

每项先记录复现输入、截图或 widget 场景；统一加载/空数据/失败/重试；候选翻译 key 逐一验证存在性和实际使用；颜色与断点复用主题体系。当前主干已有统一磨砂弹窗，按具体缺口改。

验收：失败不永久转圈；重试成功与再次失败可恢复；空态可理解；360px/横屏/大字体无裁切；亮色可读；TV 错误态与重试可达；翻译和图标检查通过。

## P7 整体视觉改版：实施规格与验收

**目标**：在独立组件稳定后统一信息层级和设备布局。**非目标**：不改变导航结构，不删功能入口，不将画稿占位海报、假人数和假数据带入产品。

先建立六画板对应的应用截图矩阵，再依赖 B2/C 整理详情布局：全幅头图、标题、纯文字元数据、评分、操作、轨道、简介/演职员/相关推荐；TV 信息区与底部推荐保持焦点连续。处理短屏、长标题、空图片、不同内容类型，禁止只适配固定390×1360或1440×900。

验收：手机360/390、平板横竖屏、桌面、TV；亮暗/OLED；大字体/长文/RTL（项目支持范围内）；图像缺失与空内容；遥控焦点和返回；截图差异人工审查，不能盲更新金图掩盖问题。

## P8 全局交互反馈：实施规格与验收

**目标**：可点击、忙碌、选中、保存反馈一致。**非目标**：不让每个控件重复造手势识别，不通过动效拖延实际动作或虚报保存成功。

B 的局部组件验证后，逐控件核对现有 InkWell/Focusable 行为，再接播放、次按钮、海报、导航和评分；保存反馈由真实结果驱动；处理双击、防重入、失败恢复。菜单选中120ms关闭的视觉建议不得牺牲操作正确性或屏幕阅读器状态。

验收：按下/抬起/取消/滚动/长按不误触；焦点与确认反馈共存；动作只发生一次；触感只有既定移动端路径；禁用无假反馈；系统减弱动画和低性能降级；加载/保存失败可恢复；TV返回焦点正常。
