# Plezy 播放器视觉改造 — 第一批

目标：参考 VidHub 的克制控制层，仅改 Plezy 自有 Flutter 代码。尚无 VidHub 实屏截图，不能宣称像素级还原。

## 本批契约
- VOD 时间轴默认 3dp，拖动/鼠标悬停/遥控聚焦时 8dp，缓冲和进度同高度、120ms 动画；触摸热区不缩小。
- 保留章节、预览缩略图、无障碍、点击/拖动 seek 语义，拖动释放只提交一次。
- 倍速与亮度/音量统一半透明深色胶囊，提示避开中心。音量/亮度提示从 54×184 缩到 42×128。
- 不改播放器参数、手势判定、弹幕、锁屏、网络、服务器库结构及他人未提交改动。

## 验证
- 先运行现有 TimelineSlider 14 项基线（已通过）。
- 新增默认/拖拽/取消/悬停/遥控/禁用/窄屏/大字体与 Painter 重绘测试。
- 运行相关播放器测试、Dart 格式/静态检查，导出生产控件的 Flutter 实际渲染 PNG。

## 已执行结果
- 主回归：201 项通过；详情页与桌面点击：67 项通过（合计 268）。

- PNG：`<local-cache>/plezy-player-ui-preview.png`，960×540，仅是生产控件测试渲染，不是完整 App/实机截图。

- 视觉查看服务两次上游报错，因此不声称已经人工核对截图或精确复刻 VidHub。
- 仅提交本批文件，不把现有弹幕/签名/依赖改动混入。
