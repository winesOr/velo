# 3.0.0 交付版本修正

用户确认上一版已经是 `2.23.27+6208`，本次明确要求迭代到 `3.0.0`。交付目标修正为 **`3.0.0+6209`**：版本名为 `3.0.0`，基础构建号从已有 `6208` 递增一次，避免沿用旧分支的过期版本目标。

本次交付保留 UI V1 九组任务的全部实现。版本脚本用于递增基础构建号，版本名按本次明确要求设置为主版本 `3.0.0`。修正打包方式和图标时不再递增版本，ABI 或渠道偏移不写回源码。

APK 恢复上一版实际采用的 `--split-per-abi` Release 构建和原开发签名。基础构建号保持 `6209`，由 Flutter 构建工具加 ABI 偏移：armeabi-v7a 为 `7209`、arm64-v8a 为 `8209`、x86_64 为 `10209`。分别对照上一版的 `7208`、`8208`、`10208` 校验递增；不将 ABI 偏移写回 pubspec.yaml。

此前通用包实际构建号 `6209` 低于已安装分包，会被 Android 识别为降级；只比较基础构建号不足以判断覆盖升级。新版交付逐包验证包名、实际构建号、ABI、签名指纹连续性、ZIP 对齐和 SHA-256，不再混用旧通用包。

Android 自适应图标前景和单色图层恢复上一版的 `0.74` 中心缩放；TV 横幅恢复新版矢量资源，并删除会优先覆盖它的旧密度 PNG。同步恢复对应品牌资源生成器，避免后续生成时回退。构建后读取每个 APK 的编译资源，与上一版实际 APK 对比这三个图标资源，而不是仅检查源码或文件名。

本次不修改 Dart 业务代码、协议、依赖或签名配置，不新增视觉测试或 golden。已有 UI 回归结果及八项达到修复轮数上限的详情字体夹具问题仍见 [全局回归记录](ui-v1-final-regression-2026-11-15.md)，不将其描述成新一次全量通过。规则检查在提交前运行。
