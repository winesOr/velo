# 播放器 V4 落地对照（原型 → 代码）

依据：`design/prototype/player.html`（2026-10-23 用户确认版）。只改手机布局（`MobileVideoControls` 及其手势）；TV / 桌面布局本轮不动。

## 一级界面

| 原型 | 代码现状 | 本轮处理 |
|---|---|---|
| 顶栏：返回、Logo 标题 + 集名 | `VideoControlsHeader` 已有 | 保留 |
| 顶栏右：一起看芯片（仅房间内） | 一起看入口在别处 | 有会话时在顶栏显示芯片 |
| 顶栏右：弹幕开关 | 弹幕按钮打开设置面板 | 改为开关（`DanmakuSession.enabled`） |
| 顶栏右：投屏 | 项目无投屏实现 | 放按钮 + 面板，面板提示「尚未支持」（用户 2026-10-23 决定） |
| 顶栏右：横竖屏切换 | 旋转锁定（固定横屏） | 改为横 / 竖切换（`OrientationHelper`） |
| 顶栏右：更多 | 齿轮 = `VideoSettingsSheet` | 打开四标签抽屉 |
| 左侧：锁屏 | 已有 | 保留，样式改为玻璃圆钮 |
| 右侧竖排：截图、画中画 | 截图在底部、画中画在顶栏 | 挪到右侧竖排 |
| 画面中间：无按钮 | 快退 / 播放 / 快进 | 去掉 |
| 底部：时间轴，无底板 | 已无底板 | 保留 |
| 底部一行：播放、下一集；倍速、字幕、选集、弹幕芯片 | 播放、上一集、下一集、一长串芯片、截图 | 按原型精简；芯片用短标签 |
| 跳过片头按钮 | 已有 | 保留 |

## 二级菜单

- **弹出卡**（倍速、字幕、选集）：在芯片上方、整排底部控件之上弹出；半透明毛玻璃，圆角 18，细边；当前项高亮打勾；跟随浅色 / 深色。
- **抽屉**（更多、弹幕芯片）：右侧浮出，四周留 10，圆角 22，顶部分段标签「视频 / 音频 / 字幕 / 弹幕」。
  - 视频：画面比例、自动跳过片头片尾、播放内核、版本与画质、画面缩放、睡眠定时（后四项进入现有子页面）。
  - 音频：音轨、音画同步、音量增益、声道。
  - 字幕：主 / 次字幕、字幕延迟、字号与位置、在线搜索。
  - 弹幕：沿用 `DanmakuSettingsSheet` 内容。
