规则

  1. 杜比双字重：DOLBY 粗 + VISION/ATMOS 细，大写字距；HDR 系列和 DTS:X 单字重。
  2. 分辨率用浅底作一行的起点，格式只描边，颜色跟随所在文字色，深浅主题与海报取色背景都成立。
  3. 固定顺序：分辨率 → 动态范围 → 空间音频；DV + HDR10+ 双层时两枚都显示。
  4. 不复刻杜比商标图形，纯字标避免授权问题。

搜索页三列海报墙：沙丘（DV + Atmos）、星际穿越（HDR10）、千与千寻（普通 AC3）、银翼杀手（DV + HDR10+ + Atmos）。

改动

  1. 位置仍在左上（试过放左下和评分并排，手机三列海报只有约 110px 宽，两者会撞），但样式改成和右下评分同一套：20px 高、6px 圆角、同一块 #000c 底，去掉图标和描边。
  2. 视频 + 音频合成一枚分段徽标（DV │ ATMOS），实机只显示第一个格式，丢掉了 Atmos。
  3. 只上高级格式：DV / HDR10 / HDR10+ / HLG / Atmos / DTS:X。普通杜比音频（AC3 / EAC3）几乎每部片都有，不再上海报（千与千寻）。
  4. 有目录标签时不再隐藏格式（实机要 badgeLabels.isEmpty 才显示）。
  5. 有目录标签（新上线 / 即将上映）时，格式排在标签下方，右上仍留给已看 / 未看集数。
  6. 评分角标顺带统一：固定 20px 高、文字垂直居中。

字体与字号

Velo 在手机和 TV 上没有内置字体，用的是系统字体：小米 / 澎湃是 MiSans，其他 Android 多为 Noto Sans CJK（思源黑体），iOS / macOS 是苹方，只有 Linux 内置 Go Noto。粗大不是字体本身，而是字号和字重定得偏重：标题几乎都是 w600，首页大标题 45px 还收紧了 −1.5 字距。下面用思源黑体示意。

建议

  1. 先不内置字体，降字重和字号：页面标题保留 w600 当唯一最重的一级，其余标题一律 w500，正文 w400。很多系统中文字体只有常规和粗体两档，w600 会直接落到 Bold，这是在手机上显得特别粗的主要原因。
  2. 中文不收紧字距：−1.5 / −0.6 这类负字距是给拉丁字母用的，中文挤在一起更显黑；改为 −0.3 以内。
  3. 想要各机型一致就内置思源黑体，效果见下一节“始终用思源黑体”。
  4. 改动集中在 home_typography.dart、mono_theme.dart 和详情页标题，一处改全局生效。

始终用思源黑体

只有这一节右边三屏是思源黑体（Noto Sans SC）：屏内所有文字，包括英文、数字和格式徽标都换成思源，并套用新的字号字重。稿里其他画面用的是你这台浏览器的系统字体。左边：当前字号字重 + 系统字体。首页原型里的楷体 Logo 换成了“无 Logo 时的文字标题”。

如果内置思源黑体

  1. 效果：小米、华为、三星、TV 盒子上字形和粗细完全一致；500 / 600 是真正的中粗，不会再落到 Bold，标题更“稳”不发黑。
  2. 代价：需要随包内置字体文件，全字库可变字体单个约 10–18 MB；按简繁常用字裁剪后可压到约 5 MB，具体以打包实测为准。首次启动多一次字体加载。
  3. 做法：pubspec.yaml 声明字体，mono_theme.dart 设 fontFamily；数字和英文也走思源（自带拉丁字形），字幕渲染不受影响（mpv / ExoPlayer 自己选字体）。
  4. 授权 SIL OFL 1.1，可商用、可随应用分发，需要在关于页 / 第三方许可里附上许可文本。

播放器：倍速下拉与磨砂面板

点底栏“1.0x”不再从右侧滑出整页抽屉，改成在按钮正上方弹出的下拉框；字幕 / 音频 / 视频 / 弹幕 / 选集这些侧边面板保留位置，材质改成磨砂。打开“改后”的播放器页面可以直接点倍速试。

改动

  1. 倍速下拉：128px 宽，锚在倍速按钮正上方 8px，从按钮处放大淡入（170ms）；2.0x … 0.5x 六档，当前项打勾 + 淡紫底，底部“更多速度…”进入完整的倍速设置。点外面或按返回关闭，焦点回到倍速按钮；TV 上方向键上下选择、确认即生效。
  2. 磨砂材质（下拉框与侧边面板共用）：深色 56% 底 + 30–34px 模糊 + 饱和度 1.7，0.5px 白 16–18% 亮边，内侧 1px 高光；实机现在是 95% 不透明，几乎看不出磨砂。
  3. 背后遮罩变浅：从压暗并模糊整个画面，改为 16% 黑、不模糊，画面透过面板仍可见。
  4. 面板内控件同步变透：分段标签、选择行、输入框改用白 6–7% 底 + 12% 描边；选中态改为淡紫 20% 底 + 浅紫字，在磨砂上不再是一块实心色。
  5. 面板位置、宽度（340）、圆角（24）和打开 / 关闭动画不变；播放器内无论深浅主题都用深色磨砂。
