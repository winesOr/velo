# Velo 最终 UI 原型基准 V1

本文件把原型变成后续真实 UI 改造的逐项验收基准：详情评分回到海报信息组，剧集连续滑动并自动同步分组，音频与字幕采用当前 Velo 的双行选择字段，通知与弹窗统一为顶部轻通知、居中对话框和锚定菜单；播放界面内的面板例外，统一为右侧抽屉。**任何弹窗与提示都不从底部滑出。**

修订：FINAL-UI-V1 · 本轮定稿。范围为七个 HTML 页面（一个总览、六个产品页）；不改 Flutter、Android 或播放器核心。当前真实样式依据源码核查，未声称与真机逐像素一致。

[打开总览](index.html) · [性能优化功能点](performance-improvements.html) · [界面优化功能点](ui-improvements.html) · [Markdown 源文件](final-ui-spec.md)

## 1. 基准如何使用

先按页面入口复现指定状态，再按组件编号检查布局、颜色、文字、交互和焦点，最后在相同尺寸/主题下比较截图。下方勾选项用于**未来真实 Velo UI 改造验收**，默认未勾选不代表 HTML 原型尚未实现。HTML 中勾选仅保存在当前浏览器；不是代码实现状态或测试报告。

优先级：本轮用户明确要求 → 本规范与定稿原型 → 早期研究文档。旧的详情海报外评分区、底部提示、按钮堆式轨道列表不再是目标。原型状态演示与服务端接口分离；不得把演示按钮、计时器、虚构媒体数据带入生产流程。

## 2. 共用视觉与动作 token

| 类别 | 定稿值 | 应用边界 |
| --- | --- | --- |
| 深色 | background #121212 / surface #202020 / text #f3f3ef / caption #adada8 | 海报取色区域独立保留 |
| 浅色 | background #f4f3ef / surface #fdfcf9 / text #242424 / caption #686864 | 不将播放HUD改成白底 |
| 品牌 | accent #6060f5；前景深 #b4aaff、浅 #6256c8；选中底深 #36324e、浅 #e9e5f6 | 选择与focus，不覆盖服务器品牌和运输按钮 |
| 圆角 | 卡片/字段14；紧凑菜单18；独立dialog与播放器设置浮层24 | 不强制所有容器同圆角 |
| 字体 | 正文14 /列表15 /区块18 /页标题22 /说明12；TV保留大尺度 | 详情和主视觉标题单独遵循组件值 |
| 字段 | 普通最小高58、compact52；padding12×8；主15/500、次12、箭头20 | 选中描边2px，默认1px/8%前景 |
| 弹层 | dialog最大宽560/宽款720，inset16，blur22，深90%/浅94% | 非播放页居中；菜单空间不足也居中，禁止bottomsheet；**播放界面一律右侧抽屉，不居中** |
| 动态 | press120ms /release180ms /menu120ms /dialog180ms | 减少动态归零；不是网络或性能参数 |

## 5. 弹层类型与一致性检查

| 类型 | 使用场景 | 定稿形式 | 关闭与焦点 |
| --- | --- | --- | --- |
