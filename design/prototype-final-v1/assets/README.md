# Prototype artwork

Historical design reference only. These files are reference artwork, not bundled Flutter product assets.

- `hero-reference.jpg`, `continue-reference.jpg`, `continue-second.jpg`: existing crops from user-provided reference screenshots in the preceding prototype.
- `detail-reference.jpg`: user-supplied screenshot from 2026-10-23; the public copy masks a sensitive path while preserving dimensions and all pixels outside the mask. CSS restricts artwork / episode / actor views to their relevant regions; this is a screen reference, not a standalone server poster.
