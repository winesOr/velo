# Velo 最终 UI 原型 V1：独立验证

验证对象：`<local-path-withheld>`。仅 HTML 交互原型，未修改或验证 Flutter/native 生产实现。

## 结果

通过。原型、最终规格和静态截图可作为后续真实 UI 改造的设计对照基线。

- 详情：电影/剧集评分均位于 `.detail-copy` 海报信息组内；只显示图标与数字；来源通过可访问名称和说明浮层提供；`ratings=none` 整组收起；不存在旧 hero 外独立评分区。
- 连续选集：默认第 4 季 27 卡，一次渲染；水平滚动跨 10→11 自动高亮 11–20，反向滚动返回 1–10；点组不改播放集；第 27 集及末组 21–27 不越界；换第 1 季 12 集、scrollLeft=0、播放第 1 集。
- TV：方向键 10→11 与反向同步焦点所属组；点击卡片接管为左缘可见分组；焦点离开列表立即恢复左缘分组。最终第 2 轮修复后专项通过。
- 音频字幕：双行选项、已选勾选、选择成功后字段及快捷入口同步、刷新保留；主字幕关闭清除次字幕、相同主次轨禁选；无音轨禁用、不支持次字幕状态、pending 禁止重入、失败保留旧值；Escape 只关最高层并恢复焦点。
- 弹层：播放设置、音轨字幕选择、投屏、设置线路表单的居中布局和窄屏边界通过；顶部轻通知不抢焦点。仅演示，不真实投屏或连接服务器。
- 回归：首页失败保留内容、单库重试不抢移开的焦点、首次加载及缓存状态；搜索空态与清空；一起看邀请码 246810 加入及准备；线路端口 65536 拒绝；三主题切换与跨页存储。
- 布局：390 手机、844 横屏、1440 桌面；播放器评审表独立横滚，页面不横溢；library 最终选中颜色为深色 `rgb(180,170,255)` / `rgb(54,50,78)`。
- 静态检查：10 个 HTML，本地 href/src 均存在，未引用外部资源；23 个外部/内联 JS 语法检查通过。
- 最终规格：390 宽无页面横溢、目录锚点有效、22 个稳定组件 ID 复选框持久化通过，测试勾选已复位。勾选用于未来真实 UI 验收，不代表本轮生产实现完成。
